Vérificateur de fiches entreprises

Un agent IA de prospection produit des fiches d'entreprises. Avant qu'un commercial s'en serve, chaque fiche est confrontée à la base officielle de l'État (SIRENE) et classée vérifiée, à corriger ou bloquée. Dans le doute, la fiche est bloquée.

Le code qui tourne dans cette page est exactement le fichier verifier.py testé dans le dépôt, exécuté dans votre navigateur. Voir le dépôt et les tests.

Corrections proposées, à valider par un humain

Les fiches saisies ne sont jamais modifiées : une correction est seulement proposée, avec sa preuve.

Les règles appliquées

  • Un SIRET mal formé (14 chiffres et chiffre de contrôle) est bloqué sans interroger la base.
  • API en panne, réponse inexploitable, plusieurs résultats ou SIRET différent : bloquée.
  • Entreprise cessée ou établissement fermé : bloquée.
  • Entreprise non diffusible : bloquée, aucune donnée recopiée. Les dirigeants ne sont jamais recopiés.
  • Code postal différent de la base officielle : à corriger, avec une proposition et sa preuve.

Chaque règle est protégée par un test qui échoue si on la retire. Limites : le premier chargement est plus lent, la page dépend de la disponibilité de l'API publique, et elle ne vérifie que ce que la base officielle contient.
